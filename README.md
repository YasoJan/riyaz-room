# Riyaz Room

A Hindustani vocal practice app: tanpura drone (built-in or your own recording), harmonium-guided alankars, paltas, meend and raag scales, live pitch scoring against just-intonation swar targets, a daily riyaz plan with a 10,000-hour log, and a recording check.

Open `index.html` over https (e.g. GitHub Pages) so the browser allows microphone access.
